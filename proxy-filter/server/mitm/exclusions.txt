# Default MITM exclusions — domains we know will refuse interception.
# One domain per line. Subdomain matches automatically (foo.example.com
# matches "example.com").
#
# When a domain is listed here, mitmproxy peeks at the TLS Client Hello
# (so we still see the SNI hostname) but does NOT decrypt — it tunnels
# the raw bytes through. We can still apply hostname-based block/allow,
# we just lose URL-level visibility for these flows.
#
# Sources:
#   - Apple, "Use Apple products on enterprise networks":
#     https://support.apple.com/en-us/101555
#   - Cisco Umbrella, "TLS Decryption — Apple App Store, iCloud, etc."
#   - mitmproxy/issues + community contributions
#   - empirical: enterprise SSL-inspection deployment notes
